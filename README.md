## What I focus on

- **Local-first products:** desktop and utility tools that keep core data on the user’s machine.
- **Agent-assisted engineering:** multi-agent orchestration, human review gates and reproducible workflows.
- **Cross-platform delivery:** Windows, browser extensions, web, iOS and Android.
- **Engineering hygiene:** automated CI, secret scanning, explicit limitations and verifiable releases.
