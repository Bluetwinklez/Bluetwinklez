## What I focus on

- **Local-first products:** useful desktop tools and workflows that can keep core data on the user’s device.
- **Agent-assisted development:** orchestration, human review and reproducible steps.
- **Cross-platform delivery:** Windows, browser, iOS and Android projects.
- **Engineering discipline:** explicit setup requirements, automated checks and honest documentation of limitations.

## Start here

1. Choose a project above and read its **README** for requirements, installation and limitations.
2. Check **Releases** for published builds where available; a repository is not necessarily a downloadable product.
3. Check **Issues**, **Pull Requests** and **Actions** for open work and validation history.

> **Project status varies.** Some repositories are active applications, others are previews or experiments. A passing CI badge does not imply real-device validation or production readiness.

## Languages & collaboration

Documentation is generally available in English, with Turkish interfaces or additional Turkish guides for projects serving Turkish workflows. If you find a reproducible issue, open a report in the relevant repository with your environment, reproduction steps and expected versus actual behavior.

For sensitive reports, use the repository’s [security reporting guidance](SECURITY.md); please do not publish credentials, personal data or exploit details in public issues.
